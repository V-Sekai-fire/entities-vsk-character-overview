# entities-vsk-character-overview

An engine project that lays out a character overview sheet around a `.vrm` avatar.

## What it is for

It holds the overview sheet's artwork, a sample avatar, and a template scene that presents the avatar against the sheet, with the `.vrm` importer and toon shader addons it needs vendored under `addons/`.

## Build and run

Open `project.godot` in the engine and run `character_overview/scenes/character_overview_template.tscn`.
